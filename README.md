# Student Info App

A simple, good-looking webpage that displays student information in a card layout.

## Student Details

- Name: John
- Register Number: 101
- Programme: MCA
- Academic Year: 2025 - 2026
- Email: john@example.com

## Features

- Card-style layout with avatar, heading, and status badge
- Clean spacing and improved typography (Google Font: Poppins)
- Icon-labeled information rows
- 🌙 / ☀️ Dark mode toggle (choice remembered via `localStorage`)
- 🖨️ Print button with dedicated print styling
- 📊 Animated attendance progress bar
- "Last viewed" timestamp
- Fully responsive layout for mobile screens

No database, backend, or advanced JavaScript is used — just plain HTML, CSS, and vanilla JS.

## Run

Open `index.html` in a web browser.
